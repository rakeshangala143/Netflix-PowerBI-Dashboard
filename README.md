# Netflix Power BI Dashboard

## Project Overview
This project analyzes Netflix content using Power BI to identify trends in movies and TV shows.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights
- Content distribution by type
- Rating analysis
- Duration trends
- Category-wise analysis
